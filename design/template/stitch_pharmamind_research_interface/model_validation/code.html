Selection Method

PharmaMind utilizes a Quality + Diversity log-determinant optimization strategy to select candidates. This ensures the final shortlist maximizes predicted efficacy while maintaining sufficient chemical diversity to mitigate downstream trial risks.

Objective Function
q = P(active) * (1 - P(toxic))

info Technical Notes

Train/Test Split Methodology:
Models were evaluated using an 80/20 train/test split. To ensure rigorous evaluation of generalizability to novel targets, a strict sequence-level separation strategy was applied.

Sequence-Level Separation:
Peptides in the test set share no more than 40% sequence identity with any peptide in the training set, mitigating data leakage and memorization artifacts.
